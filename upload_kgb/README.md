# Script Automation EHRM Upload KGB

Script Python untuk automation form filling dan file upload di website EHRM (https://ehrm.pu.go.id/)

## Setup Awal

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Download ChromeDriver
Sistem akan otomatis download ChromeDriver yang sesuai dengan versi Chrome Anda.

## Cara Menjalankan

### Buka Website EHRM
```bash
python upload_kgb.py
```

Script akan membuka browser Chrome dan navigasi ke https://ehrm.pu.go.id/

## Fitur

- ✅ Membuka website EHRM
- ⏳ Mengisi form (dalam pengembangan)
- ⏳ Upload file (dalam pengembangan)

## Persyaratan

- Python 3.7+
- Chrome/Chromium browser
- Internet connection

## Notes

- Script akan membuka browser secara maksimal
- Browser tetap terbuka untuk memungkinkan inspeksi manual
- Tekan Ctrl+C untuk menghentikan script
